a portable JSON project, in the Studio browser editor or from the CLI.

- [CLI](cli.md): commands, JSON output and exit codes for automation.
- [Project format](project-schema.md): `project.json` fields, languages, screenshots and styles.
- [Rendering](rendering.md): image and font requirements, export behavior and limits.
- [Troubleshooting](troubleshooting.md): common errors and their fixes.
- [Glossary](glossary.md): terms, editor labels and their JSON keys.
- [Development](development.md): code organization, checks and releases.
- [Changelog](https://github.com/jamshoot-apps/jamshoot-studio/blob/main/CHANGELOG.md): release notes.
