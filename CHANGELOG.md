## [1.0.0] - 2026-10-28

### Added

- Compose App Store screenshots for iPhone, iPhone Duo, iPad and Mac, with 62 built-in sizes and custom dimensions.
- Edit slides, copy, images, typography, layouts, device frames, gradients, patterns and reusable palettes in the local browser editor.
- Manage portable JSON projects with local assets and fonts; create, save, remove, import and export projects as ZIP archives.
- Use the CLI to initialize and validate projects, browse output sizes, plan exports and render screenshot batches with JSON output for automation.
- Preview and export with the same Pillow renderer; export PNGs across slides, variants, locales and sizes, with a checksum manifest.
- Work locally and offline after installation, with Python 3.11+ and an optional browser editor.
