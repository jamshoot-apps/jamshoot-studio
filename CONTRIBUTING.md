# Contributing

## Issues

Open an issue for bugs and feature requests. For a bug, include the steps to
reproduce, the expected and actual result, `jamshoot --version`, and your Python
and operating system versions. Report security issues privately as described in
[SECURITY](SECURITY.md).

## Pull requests

- Keep each pull request to one change, with tests in `tests/` for the behavior it
  changes.
- Add user-facing changes to [CHANGELOG.md](CHANGELOG.md) under `Unreleased`.
- Run the required checks listed in [Development](docs/development.md#setup-and-checks)
  before opening it. CI runs only when a maintainer starts it.
